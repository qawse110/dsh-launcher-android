## 修复「没有自动获取存储权限」（commit 4183d14）

根因：MainActivity#requestStoragePermissions 在 Android 11+ 用
SharedPreferences 的 `all_files_prompted` 一次性标记，系统「所有文件访问」页
只打开一次；用户首次退出/未授权后 app 永远不再引导 → 表现为不自动要权限。

改动（仅 MainActivity.kt）：
- 删掉 one-shot 标记，每次冷启动未授权就 openAllFilesAccessSettings()
  （仅 onCreate 触发，不骚扰）；
- 新增 awaitingAllFiles 标记，onResume 从授权页返回仍未授权时 toast 提示；
- 状态区「存储」芯片未授权时高亮 ⚠ 授权 且可点直达授权页（对齐悬浮窗芯片行为）。

验证：compileDebugKotlin 通过；CI run 34013582473 success，
产物 build/apk-dl/app-debug-apk/app-debug.apk（109MB）。

⚠️ 注意：回退 ea44fb7 后 versionCode 回到固定 37，而真机已装 r248(248)，
新包无法覆盖安装，需先卸载（丢数据）。

## 修复 dsh 会话目录 EACCES（commit 197e2c6）

真机报错：`EACCES: permission denied, mkdir '/data/user/0/com.dsh.launcher/files/.dsh/sessions/<编码后的项目路径>/session-<uuid>'`。
该目录是 dsh 的会话存储根（HOME=filesDir），app 私有目录正常不可能 EACCES；
设备未连 adb 无法实证，推断为换机/备份恢复导致目录属主非应用 uid，或缺写位。

改动（DshFlow#startDshWeb 入口新增 ensureHomeWritable 预检）：
- 目录不存在先创建（属主正确，本身即修复）；探针 mkdir+delete 判定可写；
- 不可写时逐级补 755 后重试；
- 仍失败打印逐级 mode/uid（Os.stat，标记属主异常）+「清除数据/卸载重装」结论，
  快速失败，不再让 dsh 抛原始 EACCES。

验证：compileDebugKotlin 通过；CI run 34014400251 success → app-debug.apk。
