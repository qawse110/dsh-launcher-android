# 2026-10-20

## 真机 dsh 0.2.1-rc.2 启动失败（boot 级）→ 已定位并修复

**现象**：界面停在「正在启动 dsh… 等待 dsh web 就绪」，倒计时走完失败；应用进程本身不崩。
`files/logs/web.log` 关键行：
`dsh: host preparation failed: No usable native binding found for node-addon-require-builtin-android-arm64`。

**根因（两层叠加）**

1. `.pnpm` 里同一个包并存多个版本副本（升级/回滚/修复安装都会新建目录，旧 hash 目录不清理；
   实测该树 `node-addon-require-builtin` 有 12 个副本：0.1.6 + 0.1.9 …）。
   `stub/env.mjs` 的 `findPkg()` 只返回**字典序第一个**命中 → 补丁打在旧版 0.1.6 上，
   dsh 实际加载的新版 0.1.9 仍是原生实现。日志却打印 `JS shim already applied`，极具误导性。
2. `DshFlow.runAndroidStubOnce` 只信 `stub-applied` marker（apk 戳 + dsh 版本 + 脚本指纹）。
   安装树被**同版本重装**时 marker 仍命中 → 整段 stub 被跳过，补丁永远打不上。

另发现 native-stubs.mjs 里 `spawnSync`/`unlinkSync` **从未 import**（写的是 node:fs），
导致 attachment-local vision v5 补丁每次都在「语法自检不可用」处放弃写盘（打印 WARN 但不报错）。

**修复**
- `stub/env.mjs`：新增 `findAllPkgPaths()`（pnpm 全副本 + 扁平 + 嵌套首个命中，带缓存）；
  `findPkg` 改为取 `findAllPkgPaths()[0]`。嵌套扫描恢复短路（全树递归对 558 包太贵）。
- `stub/patchers/native-stubs.mjs`：koffi / node-pty / sharp / node-addon-require-builtin
  全部改为**覆盖每个副本**；补上 `spawnSync`（node:child_process）与 `unlinkSync`。
- `DshFlow.kt`：新增 `stubPatchesPresent()` 产物健康检查——marker 命中还要校验
  `node-addon-require-builtin` 每个副本都带 `dsh-launcher-android-narb-shim-v1`，
  否则重打 stub 并打印「兼容标记命中但补丁不在安装树」。
- 新增单测 `DshFlowStubPatchTest`（5 例，含「多副本只打了一半」事故场景），`testDebugUnitTest` 全绿。
- README 补一段「.pnpm 多副本会让补丁假象」的约定说明。

**真机验收（RMX3888 / af45d401，Android 16）**
- 用固定版补丁手工补跑 stub 后 0.2.0-rc.2 立刻能起（14s）→ 反证根因；
- 再按 App 口径跑 install-dsh.mjs 装 `0.2.1-rc.2`（11 个内置插件全兼容），
  新 APK 启动：`node-addon-require-builtin JS shim done: applied=0 already=3 total=3`，
  约 20s `OK 启动完成`，`curl 3080` 返回 401（需鉴权，属正常）。

**环境侧记录（本机）**
- Gradle 9.1.0 发行包官网下载超时 → 用 `mirrors.cloud.tencent.com/gradle/` 下 zip
  解压进 `~/.gradle/wrapper/dists/gradle-9.1.0-bin/<hash>/` 并 `touch *.ok` 才可用。
- SDK 缺 `platforms;android-35` 与 `build-tools;36.0.0`，已用 sdkmanager 补装。
- **构建必须在沙箱外跑**（`dangerouslyDisableSandbox`）：沙箱会拦 `mergeReleaseAssets`
  对 `app/build/...` 的读写，报「Failed to create MD5 hash ... does not exist」。
- release APK **不可 debuggable**（flags=0x0），装上去后 `run-as` 失效；
  真机取日志改走 `adb pull /sdcard/Download/DshLauncher/logs/flow.log`
  （`FileLog.exportToShared` 在流程结束时导出）。adb pull 的 `/sdcard` 路径需
  `MSYS2_ARG_CONV_EXCL="*"`，否则 Git Bash 会把它当地址转换。
