## ⚠️ 重要更正：本轮曾误判「关页不可靠」，那是我测试代码的错

## 本轮新发现（代码级缺口，未在真机复现其后果）
**中继没有监督者，一旦退出不会被重新拉起。**
- DshFlow.startDshWeb 在 3080 已响应时提前 return（"dsh web 已在运行"），
  整段 launcher 渲染/执行被跳过 ⇒ 由 launcher 负责启动的中继也不会被补起。
- Supervisor.reviveWebIfDue 只探 WEB_PORT(3080)，**从不探 RELAY_PORT(41999)**
  （grep：Supervisor.kt 出现 RELAY_PORT 0 次）。
- 中继自身在 server error / EADDRINUSE 时 process.exit(1)（webview-cdp-relay.mjs:676），
  即它会自行退出而无人重启 ⇒ ego 会静默失效。
- 备注：我先前观察到的"中继消失"多为我的测试进程退出时被一并回收，故不声称
  已在真机复现该缺口；仅作代码级风险记录。
