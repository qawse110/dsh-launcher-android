# 许愿特化器

你说一句话，它补上你没说、但决定成品好坏的那些要求——审美、光影、材质、构图、场景、交互、验收口径。**原话一个字不改**，补充跟原话一起发出去。

## 它怎么走

回车 → 拦下 → 优化 → 你确认（或自动放行）→ 原话发出，补充进上下文。

## 常用操作

| 想做的事 | 怎么做 |
|---|---|
| 正常发送 | 回车，面板出来后点确认 |
| 这轮不想等 | 双击回车（先在优化选项里打开），或点「跳过」 |
| 优化完想直接发 | 审查模式下**再双击回车**＝确认发送（不是跳过） |
| 看这轮注入了什么 | 消息下方的「本次注入」卡片 |
| 调整本轮优化 | 「优化选项」：档位、审查或自动、英文模式、模型与思考档位、上下文 |

## 三个开关

- **只读工具**：先读几个项目文件再写要求，更准，也更慢。
- **顾问**：另一个只读模型独立复核，结论变成「必须执行」的要求带回来。
- **双击回车跳过**：默认开。600ms 内按两次回车＝这轮不优化，直接发；
  若优化已经完成（审查态），同样双击＝**确认发送**。

> 没有注入就没有卡片：跳过、关档、优化失败，都不会假装注入过。
